A little help at the table.

Varsha House is an English cooperative murder mystery for one to six detectives. Everyone investigates together. Start with two detectives and Standard difficulty for a first evening.

akshaydewalwar305@gmail.com

Support is provided by the game's creator, Akshay Dewalwar. Please describe the problem, the device model and what you were doing. Include a room code only if support needs to inspect that room. Do not send passwords, identity documents or the solution to other players.

Play on TV and phones

An internet connection is required. Players must be 18 or older. Each device asks you to explicitly confirm this and accept the table rules before creating, joining or resuming a room. This is a declaration, not verified age or identity; no date of birth or identity document is collected. You can decline and return to setup. Launch the game, choose the number of detectives and difficulty, then start a room. Phones are optional. Select Phones on the TV to show a room invitation and QR code; each phone can choose a detective and read alongside the TV.

To share the game with another group, send akshaydivyanka.in/mystery/. Share a room invitation only with people joining your investigation, because it also grants access to shared notes and progress.

Read comfortably with the remote

In a case section, Up/Down scrolls the reading area; Select reaches its controls. In an open file, Up/Down scrolls the text and Left/Right turns pages. Select reaches the page controls; Left/Right then moves between the buttons, and Up returns to the paper. Back closes the file. Mark a document as read on its final page.

At the main board, press Back twice when prompted to exit the app. Settings offers a larger reading scale.

Music and narration

Choose Listen to hear a recorded introduction or evidence file. Narration is optional and stops when you change pages, close the file, pause or hide the app. Choose Listen again to restart. Music softens while narration plays.

If there is no sound, check the television volume and Settings in the game. Music, effects, rain and narration have separate controls. Companion phones start with the soundtrack off to avoid an echo. If a recording cannot be loaded, the written case remains available.

Saving, reconnecting and expiry

Room progress is saved to the service. Keep the room code so you can join again. If the connection drops, restore internet access and retry; do not assume an unsaved action has reached other devices. Leaving the room does not erase its records.

The first envelope opens immediately. The next envelope opens after the current envelope's seven files have been read-confirmed and its three deductions completed. A room expires after 30 days without a saved action. This release has one fixed case; starting again does not create a different solution.

Table rules and unsuitable content

Keep detective names and notes about this fictional game. No harassment, hate, sexual exploitation, threats or private information about real people. Read the full table rules or review them in Settings > Table rules. That screen also resets this device's saved adult and rules confirmation.

Every note has Remove for everyone and Report & hide controls. Choose a reason and confirm: an accepted report hides the note for the whole room, while removal deletes the note from the shared notebook. In Settings > Your place at the table > Choose, use Report & hide name to replace an unsuitable alias for everyone. Anyone holding the room code can use these controls and change shared progress. Reporting a name does not ban the person or revoke their room access.

Conservative server checks screen names and notes, but can miss content or reject an innocent phrase. Private report records include the original content and reason, with up to 20 retained per room for manual operator review. For a blocked innocent phrase, try a shorter fictional alias or observation. To request room or report removal, or for help beyond the in-game controls, email the support address with the room code and a brief description. Do not forward sensitive material unnecessarily. See the privacy notice for storage and deletion details.

Fire TV availability

The website is playable now. The current Fire TV build is a testing build; an Amazon Appstore release has not yet been approved. Support is initially tested on Fire TV Stick (3rd Generation, 2020) running Fire OS 7. Other Fire OS models and Vega OS are not yet verified.
